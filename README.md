# AUREVIA CAPITAL — ULTRA-PREMIUM COMPANY INVESTOR PORTAL

> **"Clarity for Investors. Confidence for Growth."**

Aurevia Capital is a world-class, institutional-grade Company Investor Portal and corporate finance relations platform. ## 💻 How to Run

Simply open `index.html` in any modern web browser:

1. Double-click `index.html` or drag it into Chrome, Edge, Safari, Firefox, or Brave.
2. Click **"Enter Demo Workspace"** on the login screen to enter the platform.
3. Use the sidebar to explore all 21 financial modules.
4. Press `Ctrl + K` at any time to activate the Global Search palette.
